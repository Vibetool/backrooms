# 后室 · The Backrooms

还原维基共创设定《后室 The Backrooms》的第一人称 3D 网页游戏。电脑和手机（含微信内置浏览器）都能玩，不用安装。

## 玩法

- **游玩**：自由探索。实体不会攻击你，但友善实体和有害实体仍会互相作战。进场前可以调能见度和实体生成量（拉满 = 正常后室的一半）。
- **噩梦生存**：简单 / 中等 / 困难 / 地狱，实体数量分别是正常后室的 0% / 20% / 40% / 60%。屏幕顶端有 san 值和饥饿值：饥饿低于 20% 移速减半，归零时只剩原来的 1/3。实体会攻击你，友善和有害实体也会互相攻击。被杀死后可以原地重生（背包保留、清掉附近实体），或返回主页。
- **测试模式**：不自动生成实体，按 T（手机点「实体」）打开列表手动放出实体，或召唤穿着同款制服、会被实体攻击的测试人。
- 所有模式都会刷出食物和杏仁水。
- 在主页点击穿制服的人，可以把防化服换成粉、蓝、黄、紫、绿、红六种颜色。

## 两人联机

- 主页上单独一个「联机」按钮（金黄描边）。点进去可以「开一个营地」，把房号或邀请链接发给朋友；也可以「加入朋友的营地」，输入朋友给的 6 位房号。只和认识的朋友联机，没有随机配对，也没有公开的房间列表。
- 连上以后，两人一起出现在联机营地：Level 1 里一间四面封死的仓库间，中间有一顶帐篷。对准帐篷按空格走进去，选模式和起始层级（开营地的人有创意工坊地图时，还能选「我的地图」），两人都点「准备」，倒数 3 秒、灯一灭就一起出发。
- 游玩和测试模式现在都能两人一起玩；噩梦生存下一步开放，帐篷里那张卡先灰着。
- 联机时暂停菜单里有「回营地」（要对方点「同意」；回营地是新开一局，背包里的东西带不回去，提出和同意时横幅上会先说）和「离开联机」。在营地里一个人等朋友时，暂停菜单里能「复制邀请链接」。掉线或切出去回消息，两边原地等，最多 90 秒自动重连。语音是开麦 / 闭麦切换，默认闭麦。
- 营地柱子上的挂钩挂着没人穿的制服：准心对准哪件、按空格就换哪件，那件从挂钩上取下来，换下来的挂回去；队友身上那件不在挂钩上，换不到。
- 实话：没有中转服务器。两个人连同一个 Wi‑Fi 最稳；在不同的家里、尤其用手机流量时，有时候会连不上，连不上时界面会写明原因。

## 操作

- 电脑：WASD 移动，Shift 冲刺，鼠标转视角；准心对准东西，短按空格使用 / 拾取，长按空格拖动（墙、通往别层的门和出口拖不动）；F / 左键用手里的物品，1–5 选物品，Q 丢弃，Esc 暂停，V 开关麦（联机时），T 实体列表（测试模式）。
- 手机：左侧摇杆移动，右侧滑动转视角；右下角「互动」键（轻点使用 / 拾取，按住拖动），另有「使用」「冲刺」「丢弃」「暂停」键。

## 技术

- three.js r147，全部库放在 `vendor/`，只用传统 `<script>`，双击 `index.html` 也能打开（部分贴图在 `file://` 下会改用程序化兜底）。
- 联机：WebRTC 点对点，信令复用 `room.php`（服务器不改）；打洞服务器可在 `BR.config.iceServers` 配置，目前只有 STUN、没有 TURN 中转。流程和协议见 `ARCHITECTURE.md` 第 9 节。
- 接口约定见 `ARCHITECTURE.md`，层级与实体写法见 `js/levels/_TEMPLATE.md`、`js/entities/_TEMPLATE.md`。
- 测试：`node tests/smoke.mjs`（单机流程）、`tests/coop.mjs`（双浏览器联机，用内存假信令服务器，不连真实服务器）、`tests/camp.mjs`（联机营地）、`tests/items.mjs`、`tests/kit.mjs`、`tests/preview.mjs`。
