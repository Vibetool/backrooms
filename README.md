# 后室 · The Backrooms

还原维基共创设定《后室 The Backrooms》的第一人称 3D 网页游戏。电脑和手机（含微信内置浏览器）都能玩，不用安装。

## 玩法

- **游玩**：自由探索。实体不会攻击你，但友善实体和有害实体仍会互相作战。进场前可以调能见度和实体生成量（拉满 = 正常后室的一半），支持 2 人联机和开麦。
- **噩梦生存**：简单 / 中等 / 困难 / 地狱，实体数量分别是正常后室的 0% / 20% / 40% / 60%。屏幕顶端有 san 值和饥饿值：饥饿低于 20% 移速减半，归零时只剩原来的 1/3。实体会攻击你，友善和有害实体也会互相攻击。被杀死后可以原地重生（背包保留、清掉附近实体），或返回主页。
- **测试模式**：不自动生成实体，按 T（手机点「实体」）打开列表手动放出实体，或召唤穿着同款制服、会被实体攻击的测试人。
- 所有模式都会刷出食物和杏仁水。
- 在主页点击穿制服的人，可以把防化服换成粉、蓝、黄、紫、绿、红六种颜色。

## 操作

- 电脑：WASD 移动，Shift 冲刺，鼠标转视角，E 拾取，F / 左键使用，1–5 选物品，Q 丢弃，Esc 暂停，V 开关麦（联机时），T 实体列表（测试模式）。
- 手机：左侧摇杆移动，右侧滑动转视角，右下角按钮拾取 / 使用 / 冲刺。

## 设定来源与许可

层级、实体和物品设定改编自 Backrooms Wiki（英文 Wikidot、中文 Wikidot、Fandom），按 **CC BY-SA 3.0** 使用。同一内容在不同来源之间有冲突时，用随机数选取其中一个版本整体采用，不混合拼凑。每一项选中的来源与链接见 `data/credits.json`，游戏主页底部也能打开查看。

## 技术

- three.js r147，全部库放在 `vendor/`，只用传统 `<script>`，双击 `index.html` 也能打开（部分贴图在 `file://` 下会改用程序化兜底）。
- 联机：WebRTC 点对点，信令复用 `room.php`；打洞服务器可在 `BR.config.iceServers` 配置。
- 接口约定见 `ARCHITECTURE.md`，层级与实体写法见 `js/levels/_TEMPLATE.md`、`js/entities/_TEMPLATE.md`。
- 测试：`node tests/smoke.mjs`（单机流程）、`tests/coop.mjs`（双浏览器联机）、`tests/items.mjs`、`tests/kit.mjs`、`tests/preview.mjs`。
